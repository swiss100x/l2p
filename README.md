# CI Learning to Practice: live pilot page

Upload everything in this folder to the root of a new GitHub repository, then turn on GitHub Pages (Settings, Pages, deploy from `main`, root).

- `index.html` is connected to the CI database in London. It only works with a session link: `https://<your pages address>/?c=<invite_token>`.
- Before sending the link: open `index.html`, find `const ICO_NUMBER='';` and put the ICO registration number between the quotes.
- Do not add the prototype, mock-ups or results page to this repository.
- Turn on two-factor authentication for the GitHub account that owns this repository.
